# Granola

Your meetings in Granola: the AI summary, the notes you typed and the transcript.

1. In the Granola app: Settings → Account management → Export historical data → Generate CSV. Keep every workspace ticked.

2. Granola emails a link when it's ready, usually within a few hours. The link opens notes.granola.ai, so sign in there with the same account.

3. It downloads granola-export-<date>.zip to Downloads, where the app finds it. Or drop it here.

The file: `granola-export-<date>.zip with granola-export-<date>-000.csv`.
