# Telegram

Chats, replies and reactions, from Telegram Desktop.

1. In Telegram Desktop: Settings → Advanced → Export Telegram data. Choose the chats, set Format to Machine-readable JSON, and export.

2. The first time you ask, Telegram makes you wait 24 hours and tells you when to come back. Ask again then, from the same Mac.

3. It saves to Downloads/Telegram Desktop, where the app finds it. Or drop the DataExport folder here.
