# Outlook and other email

Outlook.com, Hotmail, school and work mail. Outlook.com has no web export, so it comes through Mail on this Mac.

1. System Settings → Internet Accounts → add the account with Mail turned on.
   Outlook.com and Hotmail: choose Microsoft Exchange.

2. Open Mail and leave it open until the mailbox finishes downloading.
   A large mailbox can take 10 hours or more. The count keeps rising until it is done. Homecoming reads Mail as it goes (Mail, under On This Mac), so there's nothing to export.

3. Mail kept somewhere else, like an old .mbox file or another mail app's export: give it a name above, then drop it on this page, or choose Add the Download….
