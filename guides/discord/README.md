# Discord

Every message you sent in DMs, group DMs and servers.

Where: https://discord.com/app

1. Sign in. Check it is your main account, not an auto-named secondary one.

2. If Discord asks you to verify your email, do that first. Unverified accounts can't export.

3. User Settings (gear) → Data & Privacy → Request my data → Request Data.

4. Tick Account, Messages and Servers. Leave "Your Activity" off (large usage logs).

5. Submit. The link arrives by email, usually within hours (Discord says up to 30 days).

The download link usually comes in 4 hours, at most 30 days. The file: `package.zip`.

Not in it:
- Discord exports only your own messages, never the other side.
