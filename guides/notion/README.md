# Notion

Every page and database in your workspace.

Where: https://app.notion.com/

1. Sign in to Notion.

2. Settings → General → Export → Workspace content: Export.

3. Export format: Markdown & CSV. Page content: Everything. Create folders for subpages: on. Export.

4. The link arrives by email, usually within an hour.

The download link usually comes in 1 hour, at most 1 day. The file: `Export-<id>.zip`.
